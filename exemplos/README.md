# Exemplos

Arquivos `.json` prontos para abrir no sistema em
**⋯ Mais → Abrir arquivo…** (ou arrastando para a janela).

## `WaiverRequest_SBR4_J06.json`

O relatório **SBR4 — J06** convertido a partir do PDF original, com as
31 NCRs, os textos de derrogação, os certificados impactados e as
13 páginas de evidência (imagens embutidas).

- Marco: `J06`
- Todas as NCRs entram com a situação **Waiver accepted**, conforme o campo
  *Arch Status Waiver* do documento.
- O texto de `FVxx - …` é gravado em maiúsculas e com o `FV` colado ao
  número (`FV20 - ELECTRIC SUPPLY`).

Se já existir um relatório com o marco `J06` no navegador, a tela de
mesclagem compara item a item em vez de criar um segundo relatório.
